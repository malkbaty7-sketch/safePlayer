# SafePlayer

SafePlayer مشروع مشغّل وسائط محلي. يتضمن المستودع مخطط Android الأصلي في `scaffold.sh`، وواجهة ويب عربية مستقلة جاهزة للتشغيل في `web/`. اختيرت واجهة ويب خفيفة دون اعتماديات لتعمل على الهاتف والحاسوب مباشرة، دون تغيير مخطط Android الموجود.

## تشغيل واجهة الويب

من جذر المشروع، باستخدام Python 3:

```sh
python3 -m http.server 8000 --directory web
```

افتح `http://localhost:8000`. يلزم سياق آمن (HTTPS أو localhost) لاستخدام وظائف التشفير. لا حاجة لتثبيت حزم أو إعداد خادم خلفي.

أضف ملفات صوتية أو فيديو من جهازك، ثم ابحث أو صفِّ حسب النوع واضغط على الملف لتشغيله. يمكنك إضافة الملفات إلى المفضلة وحذف نسخها من المكتبة دون حذف الملفات الأصلية. صيغ التشغيل تعتمد على دعم المتصفح. تستخدم الملفات والحسابات والمفضلة IndexedDB على المتصفح والجهاز الحاليين؛ قد يتطلب ذلك مساحة تخزين كافية، ومسح بيانات الموقع يحذفها. الحساب محلي وليس حساباً سحابياً: لا يتزامن بين الأجهزة، ولا توجد استعادة لكلمة المرور. كلمة المرور مخزنة بصورة مشتقة باستخدام PBKDF2، لكن الحساب المحلي ليس بديلاً عن حماية الجهاز. يتم تسجيل الخروج عند إعادة تحميل الصفحة؛ مفضلة الضيف منفصلة عن مفضلة كل حساب.

## تطبيق Android (مرحلة تأسيسية)

افتح المشروع الجذري في Android Studio مع JDK 17 وAndroid SDK 35، أو شغّل:

```sh
./gradlew testDebugUnitTest assembleDebug
```

ملف APK الناتج في `app/build/outputs/apk/debug/`. التطبيق يستخدم Kotlin وCompose وRoom وMedia3، ويتيح اختيار ملفات صوت وفيديو من منتقي النظام، والبحث والتصفية والترتيب حسب الاسم أو تاريخ الإضافة أو المدة أو الحجم والمفضلة واستئناف موضع التشغيل. القيم غير المتاحة تظهر في نهاية ترتيب المدة والحجم؛ أعد فحص MediaStore أو أعد اختيار ملفات SAF القديمة لتعبئتها عند توفرها. يظهر آخر ملف ذي موضع محفوظ بعد تشغيله في قسم «استكمال المشاهدة»، ويُزال من هذا القسم عند اكتماله. يمكن أيضاً الضغط على «فحص وسائط الجهاز» لمنح صلاحيات القراءة وفهرسة الصوت والفيديو المرئيين في MediaStore. الفحص اليدوي يعمل أثناء بقاء التطبيق مفتوحاً، ويمكن اختيار فحص تلقائي عبر WorkManager من الإعدادات كل ٢٤ ساعة تقريباً؛ التوقيت الفعلي يحدده النظام، وتُعاد مراجعة الأذونات عند كل تشغيل. لا يحتاج الفحص إلى الإنترنت؛ يمكن إيقافه من الإعدادات، لكن ما أُضيف قبل الإيقاف يبقى في المكتبة. ولا تُحذف السجلات القديمة عند رفض الصلاحيات أو الفحص الجزئي. قد يظهر الملف المختار يدوياً والفهرس كعنصرين لاختلاف URI، وتعود العناصر المُزالة عند إعادة الفحص. يظل المحتوى على الجهاز؛ عند إزالة عنصر من المكتبة لا يُحذف الملف الأصلي. قد يتوقف الوصول إذا أُزيل الملف أو ألغى مزوّد المستندات الإذن، وعندئذ اختره مجدداً. يمكن تشغيل رابط HTTPS مؤقت من «بث الشبكة»؛ يدعم MP4 وHLS وDASH وفق المصدر وترميز الجهاز. لا يُحفظ الرابط أو موضعه في المكتبة، لكن خادم البث يرى اتصال جهازك وقد يحتوي الرابط على بيانات حساسة؛ تجنب مشاركته. يُمنع HTTP غير المشفر بما فيه روابط المقاطع وإعادة التوجيه إليه. لا يوجد RTSP أو DRM أو Cast حالياً. يدعم المشغل تغيير السرعة، وملفات الترجمة الخارجية SRT وVTT للجلسة الحالية، ونافذة صورة داخل صورة عند دعم الجهاز. يمكن اختيار مسار ترجمة أو إيقافه، وقفل أدوات التحكم أثناء التشغيل، واستخدام الإيماءات عند إخفاء أدوات التحكم. القفل لمنع اللمس العرضي فقط وليس رقابة أبوية. جلسة MediaSession مرتبطة بواجهة المشغل فقط ولا تدعم تشغيل الخلفية. المكتبة تدعم عرض الشبكة أو القائمة وصور الفيديو المصغّرة إذا وفرها الجهاز؛ قد تعرض الصور محتوى الفيديو دون تصفية، ويمكن تعطيلها في الإعدادات. يتيح المشغل إخفاء الصورة يدوياً مؤقتاً أثناء الجلسة؛ يستمر الصوت ويعود الفيديو للظهور عند إعادة فتحه، ولا تتوفر نافذة PiP أثناء الإخفاء. هذه الميزة لا تكشف المحتوى ولا تضمن حجبه أو تمنع تجاوزها. إعدادات المظهر محفوظة محلياً بأربع لوحات ووضع فاتح أو داكن. الحد الأدنى الحالي Android 8 (API 26)؛ لم يُخفّض إلى API 21 دون اختبار توافق الاعتماديات والأجهزة.

**حدود المرحلة الحالية:** هذا ليس تنفيذ الخطة الكاملة؛ لا توجد بعد فهرسة خلفية مستمرة أو مزامنة حذف الملفات أو كشف محتوى حساس، أو حجب تلقائي أو يدوي، أو رقابة أبوية، أو حسابات Android، أو بقية الميزات المتقدمة. لا تعتمد على التطبيق كأداة حماية للأطفال. لم يُضمّن نموذج ذكاء اصطناعي أو تُدّعَ دقته. واجهة الويب مستقلة ولا تتشارك بياناتها مع Android. ملف `scaffold.sh` قديم ويكتب ملفات المشروع؛ لا تشغّله فوق المشروع الحالي. راجع `ROADMAP.md` لحالة التنفيذ.

## Firestore والإشعارات (اختياري)

يعمل التطبيق دون إعداد Firebase ودون إرسال المكتبة تلقائياً. لاستخدام «السحابة» و«حفظ سحابي»:

1. أنشئ مشروع Firebase وتطبيق Android بالمعرّف `com.malkbaty.safeplayer`، وضع ملف `google-services.json` في `app/` محلياً ثم أعد البناء. الملف مستبعد من Git. أبقِ إعدادات Firebase منفصلة لكل بيئة.
2. فعّل Anonymous Authentication وأنشئ Cloud Firestore، ثم انشر قواعد الأمان التالية قبل استخدامه (ليست قواعد اختبار مفتوحة):

```text
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/videos/{videoId} {
      allow read, delete: if request.auth != null && request.auth.uid == userId;
      allow create: if request.auth != null && request.auth.uid == userId
        && request.resource.data.keys().hasOnly(['title', 'favorite'])
        && request.resource.data.title is string && request.resource.data.title.size() <= 1000
        && request.resource.data.favorite is bool;
      allow update: if false;
    }
  }
}
```

الحفظ يتطلب تأكيداً لكل فيديو ويرسل عنوانه وحالة المفضلة فقط، وليس الملف أو URI. يعرض زر السحابة السجلات من الخادم ويتيح حذفها؛ لا توجد مزامنة أو استعادة تلقائية ولا تشغيل سحابي. الحساب المجهول مرتبط بتثبيت التطبيق وقد تفقد الوصول إلى بياناته عند مسح البيانات أو إعادة التثبيت؛ يلزم حذف السجلات قبل ذلك أو إدارتها عبر Firebase Console. إعادة الحفظ تنشئ سجلاً جديداً. انتهاء مهلة عملية كتابة أو حذف لا يضمن إلغاءها؛ تحقق من القائمة قبل إعادة المحاولة. تحقق من قوانين الخصوصية والتكاليف وحماية مشروع Firebase قبل النشر. يجب اختبار الاتصال والقواعد على مشروعك؛ لم تُضمّن بيانات مشروع فعلي.

إشعارات اكتمال الفحص معطلة افتراضياً ويمكن تفعيلها من إعدادات التطبيق، مع منح إذن Android عند طلبه؛ يمكن تعطيلها من التطبيق أو النظام. تظهر أيضاً رسالة قصيرة عند تغيير المفضلة. الفحص اليدوي يعمل أثناء تشغيل التطبيق؛ الفحص الدوري اختياري ويعمل عبر WorkManager.

## بناء الإصدار

يمكن توليد حزمة AAB غير موقعة للفحص باستخدام `./gradlew bundleRelease`، وتوجد في `app/build/outputs/bundle/release/`. تُبنى الحزمة أيضاً في GitHub Actions. هذه ليست حزمة جاهزة للنشر: يجب اختبار الأجهزة والميزات وقواعد Firebase وتوفير سياسة خصوصية حقيقية وضبط إصدار وتوقيع الإصدار بأمان في بيئة المالك. لم يُضف مخزن مفاتيح أو سر إلى المستودع، ولم يُفعّل تصغير R8 قبل اختباره.

## اختبارات Android

تشغّل CI اختبارات الوحدة وتبني APK للاختبارات وحزمة AAB غير موقّعة. وتُشغَّل اختبارات Android، بما فيها فتح الإعدادات والتحقق من رابط البث وترحيل قاعدة البيانات، على محاكيَي API 26 وAPI 35 في طلبات الدمج. محلياً، شغّل محاكياً أو صِل جهازاً ثم نفّذ `./gradlew connectedDebugAndroidTest`. لا يغني المحاكي عن اختبار PiP والوسائط والصلاحيات على أجهزة فعلية.

## ملاحظات الأداء

الصور المصغّرة اختيارية ومحلية فقط. يستخدم التطبيق ذاكرة LRU بحد أقصى ٨ MiB (٢ MiB على الأجهزة منخفضة الذاكرة)، ولا يشغّل أكثر من طلبي تحميل مع قائمة انتظار محدودة؛ يُحاول إلغاء الطلبات عند مغادرة البطاقة وتُفرّغ الذاكرة عند ضغط الذاكرة أو تعطيل الصور أو إعادة الفحص. لا تُخزّن الصور على القرص. يستمر المشغّل في تحرير ExoPlayer وMediaSession عند مغادرة الشاشة؛ لا توجد خدمة تشغيل في الخلفية. هذه حدود تصميم وليست نتائج قياس: يلزم اختبار الذاكرة والبطارية على أجهزة فعلية قبل إعلان تحسّنها. لا يوجد حالياً نموذج AI لتحسينه.

### معادل الصوت

يمكن تفعيل معادل صوت مؤقت من شاشة المشغّل وضبط الحزم التي يوفرها الجهاز. يسري على جلسة المشغّل الحالية فقط، ولا تُحفظ مستوياته بعد مغادرة الشاشة. قد لا يتوفر على بعض الأجهزة أو مسارات الصوت؛ يعرض التطبيق رسالة عند تعذر استخدامه. لا يُعد المعادل رقابة أبوية أو كشفاً للمحتوى.

### تجربة المكتبة والمشغّل

تعرض المكتبة اختصارات لآخر ملف قابل للاستئناف، والملفات المضافة مؤخراً، والمفضلة عند توفرها. تختفي الاختصارات عند تطبيق بحث أو فلتر، ويمكن مسح الفلاتر دفعة واحدة. تشرح المقدمة القابلة للتخطي إضافة الملفات وأذونات الفحص. يجمع زر «المزيد» خيارات المشغّل الثانوية، بينما تبقى أزرار التشغيل والتنقل متاحة. عند فقد الوصول لملف يمكن إعادة اختياره؛ قد يُضاف كمدخل جديد إذا تغيّر معرّفه.

### السجل والمشاهدة لاحقاً

يمكن إضافة أي عنصر إلى «شاهد لاحقاً» من بطاقته وإزالته منها؛ تُحفظ القائمة محلياً وتبقى عند إعادة الفحص. يعرض «سجل التشغيل» الملفات التي بدأ تشغيلها، مرتبة حسب آخر تشغيل افتراضياً؛ يمكن تغيير الترتيب أو دمج الفلاتر، ولا يسجل البث المؤقت. الإزالة من المكتبة تزيل العنصر من القائمتين ولا تحذف الملف الأصلي. لا تتوفر حالياً إدارة مستقلة لمسح السجل أو مزامنته.

راجع `RELEASE_CHECKLIST.md` للتحقق من الأجهزة، والأداء، والخدمات، وإصدار التطبيق. هذه القائمة ليست إثباتاً بأن الاختبارات اليدوية قد نُفذت.

### الفصول

يعرض المشغّل فصول ID3 من نوع CHAP عندما يوفّرها Media3 في بيانات الملف، ويتيح الانتقال إلى بدايتها إذا كان البحث متاحاً. لا يمثل ذلك دعماً عاماً للفصول: فصول MKV وM4V وغيرها غير مدعومة حالياً، وقد لا تتوفر بيانات ID3 في بعض المصادر. لم يُختبر التشغيل بفصول على أجهزة فعلية.
